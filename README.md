# Axia — 3D Live Companion

Web-App für iPhone (Safari) und Desktop.

## Auf dem iPhone öffnen

1. GitHub Pages einschalten: Repo **Settings → Pages → Source: GitHub Actions** (einmalig).
2. URL: https://weezygizi-ai.github.io/axia-companion/
3. In **Safari** öffnen (nicht in der Grok-App).
4. Teilen → **Zum Home-Bildschirm**.
5. **GLB laden** oder Preset tippen.

TTS (sie spricht) geht. Mikrofon-Eingabe in Safari oft nicht.
